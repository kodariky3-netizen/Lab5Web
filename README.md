# Lab5Web
# PRAKTIKUM 5 - JAVASCRIPT DASAR DAN MANIPULASI HTML

## Identitas Praktikum
- Mata Kuliah: Pemrograman Web
- Pertemuan: 6
- Topik: JavaScript Dasar dan Manipulasi HTML
- Program Studi: Teknik Informatika

## A. Tujuan Praktikum
1. Memahami sintaks dasar JavaScript.
2. Menggunakan variabel, tipe data, operator, percabangan, perulangan, dan function.
3. Menampilkan informasi menggunakan Console, Alert, dan Prompt.
4. Memanipulasi elemen HTML menggunakan JavaScript.
5. Membuat interaksi sederhana pada form dan melakukan validasi input.

## B. Struktur Folder

```text
lab5_javascript/
│
├── index.html
├── script.js
└── README.md
```

## C. Langkah Kerja

1. Membuat folder bernama `lab5_javascript`.
2. Membuat file `index.html` dan `script.js`.
3. Menghubungkan JavaScript dengan HTML menggunakan tag script.
4. Menuliskan kode program sesuai latihan pada modul.
5. Menjalankan program menggunakan browser.
6. Menguji setiap fungsi dan memeriksa hasilnya.

## D. Hasil Praktikum

### 1. Latihan 1 - Menampilkan Output
Menampilkan tulisan Hello World pada halaman HTML dan Console menggunakan JavaScript.

### 2. Latihan 2 - Alert dan Prompt
Menggunakan prompt untuk meminta nama pengguna dan alert untuk menampilkan pesan.

### 3. Latihan 3 - Function dan Operasi Aritmetika
Membuat function untuk melakukan operasi penjumlahan, pengurangan, perkalian, pembagian, dan modulus.

### 4. Latihan 4 - Percabangan If-Else
Membuat program untuk menentukan kelulusan mahasiswa berdasarkan nilai minimal 60.

### 5. Latihan 5 - Percabangan Switch
Membuat program untuk menampilkan nama bilangan berdasarkan pilihan angka 1 sampai 5.

### 6. Latihan 6 - Bilangan Genap atau Ganjil
Membuat form untuk memeriksa apakah bilangan yang dimasukkan termasuk genap atau ganjil.

### 7. Latihan 7 - Mengubah Warna Halaman
Menggunakan function untuk mengubah warna latar belakang halaman menjadi hijau, putih, atau kuning.

### 8. Latihan 8 - Checkbox Menu Makanan
Membuat daftar menu makanan menggunakan checkbox dan menghitung total harga secara otomatis.

## E. Mini Project - Kalkulator Nilai Mahasiswa

Membuat program untuk menghitung nilai akhir mahasiswa berdasarkan tiga komponen:

- Nilai Tugas: 30%
- Nilai UTS: 30%
- Nilai UAS: 40%

Program menentukan nilai akhir, predikat A sampai E, serta status kelulusan mahasiswa.

## F. Cara Menjalankan Program

1. Buka folder `lab5_javascript` menggunakan Visual Studio Code.
2. Pastikan file `index.html` dan `script.js` tersedia.
3. Klik kanan pada file `index.html`.
4. Pilih Open with Live Server.
5. Program akan terbuka pada browser.
6. Lakukan pengujian pada setiap bagian program.

## G. Kesimpulan

Berdasarkan praktikum yang telah dilakukan, JavaScript dapat digunakan untuk membuat halaman web menjadi lebih interaktif. Melalui praktikum ini, saya mempelajari penggunaan variabel, operator, function, percabangan, serta manipulasi DOM. Saya juga dapat membuat form sederhana, melakukan validasi input, dan mengembangkan kalkulator nilai mahasiswa menggunakan JavaScript.
